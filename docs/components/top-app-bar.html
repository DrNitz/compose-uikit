ComposeKitTopAppBar

Material 3 top app bar with a title, an optional subtitle, a leading slot and trailing actions.

No preview yet.
Add docs/media/top-app-bar/preview.webp

Install

build.gradle.kts
implementation("com.github.DrNitz/compose-uikit:lib:v0.1.0")

Or from a clone: implementation(project(":lib")).

Usage

Kotlin
ComposeKitTopAppBar(title = "Inbox", subtitle = "3 unread")

Demo source

Kotlin
ShowcaseSection("TopAppBar") {
        ComposeKitTopAppBar(title = "Inbox", subtitle = "3 unread")
    }

This is the block the demo app renders, so it is what produced the preview above.
