ComposeKitChatBubble

A single chat message. Own messages align right and use the container colour, incoming ones align left, so bubble tails point the right way.

No preview yet.
Add docs/media/chat-bubble/preview.webp

Install

build.gradle.kts
implementation("com.github.DrNitz/compose-uikit:lib:v0.1.0")

Or from a clone: implementation(project(":lib")).

Usage

Kotlin
ComposeKitChatBubble(message = "On my way", isMine = true, timestamp = "09:41")

Demo source

Kotlin
ShowcaseSection("Chat bubbles", contentPadding = PaddingValues(0.dp)) {
        Column {
            ComposeKitChatBubble(
                message = "Hey, is the build green?",
                timestamp = "09:41",
            )
            ComposeKitChatBubble(
                message = "Yep — APK is on the artifacts page",
                isMine = true,
                timestamp = "09:42",
            )
        }
    }

This is the block the demo app renders, so it is what produced the preview above.
