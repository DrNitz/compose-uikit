ComposeKitChatInput

Message composer: a growing text field plus a send button that disables itself on blank input. Stateless on purpose — hold the text wherever you like.

No preview yet.
Add docs/media/chat-input/preview.webp

Install

build.gradle.kts
implementation("com.github.DrNitz/compose-uikit:lib:v0.1.0")

Or from a clone: implementation(project(":lib")).

Usage

Kotlin
var draft by remember { mutableStateOf("") }
    ComposeKitChatInput(value = draft, onValueChange = { draft = it }, onSend = { send(draft); draft = "" })

Demo source

Kotlin
ShowcaseSection("Chat input", contentPadding = PaddingValues(0.dp)) {
        ComposeKitChatInput(
            value = draft,
            onValueChange = { draft = it },
            onSend = { draft = "" },
        )
    }

This is the block the demo app renders, so it is what produced the preview above.
