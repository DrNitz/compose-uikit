ComposeKitClock

Self-updating clock. Renders the device time and refreshes itself on a ticker, so it keeps counting without the caller driving recomposition.

No preview yet.
Add docs/media/clock/preview.webp

Install

build.gradle.kts
implementation("com.github.DrNitz/compose-uikit:lib:v0.1.0")

Or from a clone: implementation(project(":lib")).

Usage

Kotlin
ComposeKitClock(showSeconds = true)

Demo source

Kotlin
ShowcaseSection("Clock") {
        ComposeKitClock(label = "Local time", showSeconds = true)
    }

This is the block the demo app renders, so it is what produced the preview above.
