ComposeKitClock

Neumorphic analog clock: a soft-shaded face with recessed markers, embossed numerals and three hands. The dial is drawn to the design's own proportions, so it stays correct at any size — the geometry is derived from the box it is given rather than hard-coded. It paints its own background, which neumorphism needs: the raised and recessed shadows only read as depth against the surface they sit on, so the component fills its bounds with the base colour. The hands are driven by the device clock. The second hand steps once per second, matching the design's 60-step sweep; the minute and hour hands sweep continuously between ticks.
