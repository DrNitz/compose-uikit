ComposeKitReaderCard

A story card that scrolls in place and grows into a full reader. Closed, it is a small page of prose under a soft edge fade with an "Open" pill. Tapping it expands the card's own rectangle into a reading panel — the panel is laid out at its final size from the start and only a rounded-rect clip grows, so the text never re-wraps mid-flight. The reader opens on the passage the card was scrolled to, flashes that passage once, and keeps your place when you step the type size up or down. Everything is measured from the container, so the same component works in a 400dp column or full screen. Dismiss with the close button, a tap outside the panel, or the system back gesture. Approximations, because Compose has no direct equivalent: the liquid-glass refraction is a translucent tint over a blurred backdrop rather than a real displacement map, and the drop cap is a raised initial because text cannot wrap around a floating letter.

Install

build.gradle.kts
implementation("com.github.DrNitz:compose-uikit:v0.1.0")

Or from a clone: implementation(project(":lib")).

Usage

Kotlin
ComposeKitReaderCard(
        title = "The Clockmaker's Apprentice",
        chapterLabel = "Chapter One",
        excerpt = excerptParagraphs,
        chapter = chapterParagraphs,
        resumeAfter = "On the bench lay a watch with no face",
    )

Demo source

Kotlin
ShowcaseSection("Reader card", contentPadding = PaddingValues(0.dp)) {
        ComposeKitReaderCard(
            title = "The Clockmaker's Apprentice",
            chapterLabel = "Chapter One",
            meta = "Demo content",
            excerpt = SampleExcerpt,
            chapter = SampleChapter,
            resumeAfter = ResumeSnippet,
            modifier = Modifier.fillMaxWidth().height(640.dp),
        )
    }

This is the block the demo app renders, so it is what produced the preview above.

Parameters

ParameterTypeDefaultDescription
titleString—heading on both the card and the reader.
excerptList<String>—paragraphs shown scrolling inside the card.
chapterList<String>—paragraphs of the reader body.
modifierModifierModifier—
chapterLabelString"Chapter One"small centred label above the body, e.g. "Chapter One".
metaString?nulloptional line under the reader title, e.g. "Demo content".
resumeAfterString?nullsnippet from chapter the card is showing. The reader opens scrolled to that paragraph and flashes the highlight from the snippet to the paragraph's end. Ignored when null.

sceneHeightDp640.dpheight of the whole scene when the caller's modifier does not set one.
