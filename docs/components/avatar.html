ComposeKitAvatar

Circular avatar built from initials, with an optional presence dot. Deliberately no image loading: pass a name and it works offline.

No preview yet.
Add docs/media/avatar/preview.webp

Install

build.gradle.kts
implementation("com.github.DrNitz/compose-uikit:lib:v0.1.0")

Or from a clone: implementation(project(":lib")).

Usage

Kotlin
ComposeKitAvatar(name = "Ada Lovelace", size = 48.dp, online = true)

Demo source

Kotlin
ShowcaseSection("Avatars") {
        Row(horizontalArrangement = Arrangement.spacedBy(12.dp)) {
            ComposeKitAvatar(name = "Ada Lovelace", size = 48.dp, online = true)
            ComposeKitAvatar(name = "Grace Hopper", size = 48.dp)
            ComposeKitAvatar(name = "Alan Turing", size = 48.dp, online = true)
        }
    }

This is the block the demo app renders, so it is what produced the preview above.
