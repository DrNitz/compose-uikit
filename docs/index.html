Jetpack Compose

Compose UI Kit

Reusable composables written once and shared: the library is a dependency for other apps, the demo app is the APK on your phone, and both render the same component code.

View on GitHub Get the demo APK

Components

ComposeKitTopAppBar

Top app bar with kit styling.

ComposeKitClock, ComposeKitClockPill

Live clock and compact pill.

ComposeKitChatBubble

Chat message bubble.

ComposeKitChatInput

Text input for chat screens.

ComposeKitAvatar

User avatar.

ComposeKitShowcase

Renders every component on one page.

Use it

implementation(project(":lib"))

Once published to JitPack: implementation("com.github.<user>.<repo>:lib:<tag>"). The debug APK is attached to every CI run as the artifact compose-uikit-demo-debug — see Actions.
