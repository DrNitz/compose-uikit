Jetpack Compose

Compose UI Kit

Reusable composables written once and shared: the library is a dependency for other apps, the demo app is the APK on your phone, and both render the same component code.

Use it

build.gradle.kts
implementation("com.github.DrNitz/compose-uikit:lib:v0.1.0")

Published with JitPack from tag v0.1.0. Not tagged yet? Clone the repo and use implementation(project(":lib")). The debug APK is attached to every CI run as the artifact compose-uikit-demo-debug — see Actions.
